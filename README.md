
# 🍔 FoodieExpress – Food Delivery Website

##  About the Project
FoodieExpress is a simple and attractive food delivery website created as a college mini-project. Users can explore popular food items, search for dishes, and interact with a basic shopping cart counter.

## ✨ Features
- Attractive homepage and navigation bar
- Food menu with images and prices
- Search food items by name
- Add-to-cart buttons with a cart counter
- Responsive design for mobile and desktop
- Hover effects and smooth navigation

## 🛠️ Technologies Used
- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Search and cart functionality
- GitHub – Code repository
- GitHub Pages – Website hosting

## 📁 Project Files
- `index.html` – Main webpage
- `style.css` – Website styling
- `script.js` – Interactive features
- `README.md` – Project documentation

## 🚀 How to Run
1. Download or clone this repository.
2. Open the folder in VS Code.
3. Open `index.html` in your browser.
4. Search for food and test the Add buttons.

## 🌐 Live Website
Visit the live website using the GitHub Pages link configured for this repository.
